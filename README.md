# 🧶 CozyLoops - Handmade Crochet E-commerce Platform

CozyLoops is a full-stack e-commerce platform for handmade crochet creations, built with the MERN stack (MongoDB, Express.js, React, Node.js).

## ✨ Features

- **Beautiful Landing Page** with animated floating elements and crochet-themed design
- **Product Management** - Add, edit, delete products with multiple images
- **Category Management** - Organize products into categories
- **Video Feed** - Upload and showcase crochet tutorials and showcases
- **Wishlist** - Save favorite items
- **Shopping Cart** - Add items, update quantities
- **Admin Dashboard** - Full analytics and content management
- **Responsive Design** - Works on all devices
- **Dark/Light Mode** - Toggle themes
- **Premium UI** - Glassmorphism, animations, and elegant design

## 🛠️ Tech Stack

### Frontend
- React.js (Vite)
- Tailwind CSS
- React Router DOM
- Framer Motion
- SwiperJS
- Axios
- React Hot Toast

### Backend
- Node.js
- Express.js
- JWT Authentication
- MongoDB Atlas
- Mongoose
- Cloudinary (File Uploads)
- Multer
